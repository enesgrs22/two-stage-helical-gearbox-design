# Two-Stage Helical Gearbox Design

This project presents the mechanical design and engineering
calculation of a two-stage helical gearbox developed as part of
the Machine Elements II course at Istanbul Technical University.

The project covers the complete design process from gear sizing
and shaft calculations to bearing selection, keyed connections,
sealing elements and the final gearbox assembly drawing.

## Design Specifications

| Parameter | Value |
|---|---:|
| Input power | 7 kW |
| Input speed | 2450 rpm |
| Total transmission ratio | 6.7 |
| First-stage ratio | 3.35 |
| Second-stage ratio | 2.0 |
| Normal module | 2.5 mm |
| Helix angle | 20° |

## Gear Configuration

| Stage | Pinion Teeth | Gear Teeth |
|---|---:|---:|
| First Stage | 20 | 67 |
| Second Stage | 35 | 70 |

## Design Tasks

- Helical gear sizing
- Gear strength calculations
- Shaft diameter estimation
- Shaft-hub connection design
- Key sizing and verification
- Bearing load calculations
- Bearing selection and life evaluation
- Seal selection
- Lubrication considerations
- Gearbox housing design
- Assembly and manufacturing drawing

## Bearing Selection

- Input shaft: 6207
- Intermediate shaft: 6011
- Output shaft: 6012

## Materials

16MnCr5 steel was selected for several drivetrain components,
while the gearbox housing was designed using GGG40 cast iron.

## Deliverables

- Engineering calculation report
- Complete gearbox assembly drawing
- Bill of materials
